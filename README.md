# 🌍 Eco-Sphere: Augmented Reality Learning Platform

**Eco-Sphere** is an interactive web-based application designed to teach students about environmental conservation through 3D visualization and Augmented Reality (AR).

---

## 👥 The Team
* **Member 1:** UI/UX Architect & Frontend Developer 
* **Member 2:** Logic Engineer & AR Integration Specialist
* **Member 3:** Data Manager & Technical Researcher

---

## 🚀 Key Features
* **Interactive 3D Dashboard:** A "Glassmorphic" interface to track eco-progress.
* **12 Environmental Missions:** Interactive lessons ranging from Air Quality to Forest Conservation.
* **Augmented Reality (AR):** View 3D models of the Earth and environmental hazards in your real-world space using WebXR.
* **Gamified Experience:** An AR "Trash-Dash" game to engage students in waste management.
* **Progress Persistence:** Automatic saving of learning milestones using LocalStorage.

---

## 🛠️ Tech Stack
| Layer | Technology |
| :--- | :--- |
| **Frontend** | HTML5, CSS3 (Flexbox/Gradients) |
| **3D Engine** | Google <model-viewer> (Three.js based) |
| **AR Technology** | WebXR API / Scene Viewer |
| **Scripting** | Vanilla JavaScript (ES6+) |
| **Storage** | Web Storage API (localStorage) |
| **Hosting** | GitHub Pages & GitHub CDN |

## 📂 Project Structure
- `/index.html` - Welcome & Login Screen

- `/learn.html` - 3D Learning Modules
- `/models` - Optimized .glb 3D Assets
- `/assets` - Graphics, Icons, and Stylesheets
